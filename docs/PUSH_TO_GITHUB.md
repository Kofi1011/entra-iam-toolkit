# Push this to GitHub in 5 commands

1. Create an empty repo on GitHub named **entra-iam-toolkit** (no README, no .gitignore).
2. In this folder, run:

```bash
git init
git add .
git commit -m "Initial commit: Entra ID IAM governance & access automation toolkit"
git branch -M main
git remote add origin https://github.com/<your-username>/entra-iam-toolkit.git
git push -u origin main
```

3. On GitHub: Settings → add topics `iam, entra-id, azure-ad, microsoft-graph, powershell, security, sc-300`.
4. Pin the repo on your profile.
5. Wait for the green **CI passing** badge, then add the repo link to your resume + LinkedIn.
